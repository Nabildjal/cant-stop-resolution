# Résolution de Can't Stop par Value Iteration

Ce projet propose une solution optimale au jeu de dés **Can't Stop** en utilisant des méthodes d'Intelligence Artificielle.

## 🧠 Concepts Clés
- **Value Iteration** : Algorithme utilisé pour calculer la stratégie optimale.
- **Modélisation MDP** : Utilisation de Processus de Décision Markoviens pour gérer l'incertitude des dés.

## 💻 Stack Technique
- **Langage C** : Pour la rapidité des calculs de convergence.
- **Python** : Pour les scripts de test et de simulation.
